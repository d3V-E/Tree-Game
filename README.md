# Tree-Game

It is a clicker game where you click on a tree to earn score

<img width="792" height="440" alt="image" src="https://github.com/user-attachments/assets/6a926b79-e123-4020-8beb-a90f4ca94b33" />


When you earn score you can convert it into logs by clicking on the log icon

You can convert score into logs
<img width="743" height="548" alt="image" src="https://github.com/user-attachments/assets/bfe25671-ae74-4d64-9553-ac9f73d047ba" />


Multiplier depends on the weather which changes every 300 seconds / 5 minutes and every 5 minutes some of the logs may go missing as a part of the game feature (disasters)


In the shop you can spend your logs to buy more click power to earn more logs
